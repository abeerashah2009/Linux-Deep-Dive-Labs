# Lab 21 - Package Management: APT

## Objective
Learn how to update package lists, search for packages, install software, and remove software using APT.

## Commands Used

```bash
sudo apt-get update
apt-cache search editor
sudo apt-get install vim
vim --version
sudo apt-get remove vim
```

## Result

Successfully updated package lists, searched for available packages, installed the Vim text editor, verified its installation, and removed it using APT.
